# TaskFlow

Projeto inicial de gerenciador de tarefas, criado com Vite e TypeScript.

## Stack

- Vite
- TypeScript
- CSS

## Como rodar

```bash
npm install
npm run dev
```

Outros scripts: `npm run build` (checagem de tipos e build de produção) e `npm run preview` (serve o build localmente).

## Status

Base criada a partir do template do Vite: a página atual é a de exemplo, com um contador. O gerenciamento de tarefas ainda não foi implementado.
